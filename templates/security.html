Professional Requirements

Website and Operations Requirements

Readiness criteria for a professional surveillance robot dashboard.

Configure System

Functional Requirements

  • Display a real-time robot camera stream with a visible live state.
  • Show AI detections, confidence, time, and location for operator review.
  • Provide manual robot control with clear stop and return-home actions.
  • Track robot GPS and recent detection locations on the live map.

Security Requirements

  • Restrict dashboard access to authenticated operators.
  • Use CSRF protection on every command or account-changing action.
  • Keep command controls behind role-aware operator accounts.
  • Log threat events and preserve evidence images when enabled.

Performance Requirements

  • Keep the video feed responsive on desktop and tablet screens.
  • Refresh robot telemetry without blocking the interface.
  • Handle missing camera, GPS, or detection data with clear fallbacks.
  • Use focused tables and cards so operators can scan quickly.
